# Student Score Calculator

## Project Description
The Student Score Calculator is a web application designed to calculate students' academic scores and grades automatically.

It allows users to enter scores for five students across three Continuous Assessment (CA) tests and one examination. The application automatically calculates the total score and assigns the appropriate grade using JavaScript.

## Features
- Supports five students.
- Input fields for CA 1, CA 2, CA 3 and Examination scores.
- Automatic total score calculation.
- Automatic grade assignment.
- Updates results immediately when scores change.
- Simple and responsive user interface.

## Technologies Used
- HTML5 – Webpage structure.
- CSS3 – Styling and layout.
- JavaScript – Score calculations and grade assignment.

## Grading System

| Total Score | Grade |
|---|---|
| 70–100 | A |
| 60–69 | B |
| 50–59 | C |
| 45–49 | D |
| 40–44 | E |
| 0–39 | F |

## How to Use
1. Open the application in a web browser.
2. Enter each student's CA scores.
3. Enter the examination score.
4. View the automatically calculated total and grade.
5. Change any score to see the result update immediately.
